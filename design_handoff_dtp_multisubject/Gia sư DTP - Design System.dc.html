Giải giúp em phương trình x² − 5x + 6 = 0 và giải thích từng bước ạ.
D

Đây là phương trình bậc hai dạng ax² + bx + c = 0 với a=1, b=−5, c=6. Ta dùng công thức nghiệm:

Δ = b² − 4ac = 25 − 24 = 1  →  x = (5 ± 1) / 2

Vậy x₁ = 3 và x₂ = 2. Em có thể kiểm tra lại bằng định lý Viète: x₁+x₂ = 5, x₁·x₂ = 6. ✔️

Câu 1.● Dễ

Nghiệm của phương trình x² − 5x + 6 = 0 là:

A. x = 1; x = 6
B. x = 2; x = 3 ✔
C. x = −2; x = −3
D. Vô nghiệm
Xem lời giải

Δ = 25 − 24 = 1 > 0 → x = (5 ± 1)/2 → x = 3 hoặc x = 2.

Câu 2.● TB

Cho hàm số y = ax². Đồ thị đi qua điểm (2; 8). Giá trị của a là:

A. a = 2 ✔
B. a = 4
C. a = 1/2
D. a = 8
Xem lời giải

Thay (2; 8): 8 = a·2² = 4a → a = 2.
